제안요청서(RFP) 과업 분석 및 벤치마킹 명세

과업지시서에 명시된 사업명 '공공데이터 기반 다차원 상권·입지 분석 및 인사이트 리포트 플랫폼 구축(Biz-Compass)'을 바탕으로 현행 공공데이터 조회의 구조적 한계를 분석하고, 예비 창업자와 지자체 분석가를 지원하기 위한 시스템 차별화 목표를 수립했습니다[cite: 1].

분석 항목 현행 공공데이터포털 / 시중 상권분석 (As-Is)[cite: 1] Biz-Compass 플랫폼 구축 방향 (To-Be)[cite: 1]
데이터 표현 방식[cite: 1] 단순 그리드 테이블 형태의 텍스트 데이터 조회, 시각적 직관성 결여[cite: 1] GIS 좌표 기반의 실시간 공간 버퍼링, 반경 원 및 행정동 폴리곤 시각화[cite: 1]
분석 알고리즘 깊이[cite: 1] 단일 지표 단순 나열 (단순 점포 수, 통신사 유동인구 숫자만 개별 표출) 유동인구 흐름(+) + 경쟁 점포 밀집도(-) + 배후 세대수를 결합한 복합 스코어링 엔진[cite: 1]
후보지 의사결정 지원[cite: 1] 후보지를 각각 따로 검색하여 사용자가 수작업으로 지표를 기억하고 대조해야 함 A/B 후보 상권 1:1 맞대응 실시간 교차 대조 모드 및 정량적 상권 우위 판정[cite: 1]
비용 및 리스크 관리 임대료와 매출을 연계하지 못해 과밀 경쟁 골목 진입 후 폐업하는 사례 빈번 국토부 실거래가 기반 임대료 시세 추정과 5개년 시계열 차트 및 폐업률 경보 제공[cite: 1]
결과 산출물 도출[cite: 1] 단순 화면 캡처 수준에 그쳐 실제 사업계획서 제출용 증빙 불가 원클릭 인쇄용 종합 리포트 자동 생성 뷰어 및 원천 데이터 UTF-8 CSV 익스포트[cite: 1]

공공데이터포털 오픈 API 연계 규격 및 캐싱 검토서

과업지시서 2장 가목(데이터 파이프라인)에 따른 공공 상권정보 및 실거래가 인터페이스 규격 분석[cite: 1]

1. 소상공인시장진흥공단 상가(상권)정보 API[cite: 1]

REST / JSON[cite: 1]

• 기본 엔드포인트: https://apis.data.go.kr/.../storeListInRadius

• 요청 파라미터(Request):

  • radius : 검색 반경 거리 (300, 500, 1000m)[cite: 1]
  • cx, cy : 중심 기준점 경도/위도 좌표 (WGS84)
  • indsLclsCd : 상권 표준 업종 대분류 코드 (외식, 소매, 서비스 등)[cite: 1]

• 응답 필드(Response): bizesId(업소ID), bizesNm(상호명), lon/lat(좌표)

엔지니어링 검토 결론:

사용자가 지도를 이동하거나 반경을 바꿀 때마다 공공 API를 직접 호출하면 일일 트래픽 쿼터(1,000회 제한) 초과 및 지연이 발생하므로, 백엔드 PostGIS 공간 DB에 사전 적재하고 IndexedDB 기반 클라이언트 캐싱 계층을 구축해야 함[cite: 1].

2. 국토교통부 상업·업무용 부동산 실거래가 API

REST / XML

• 기본 엔드포인트: https://apis.data.go.kr/.../getNRGTradeList

• 요청 파라미터(Request):

  • LAWD_CD : 5자리 법정동 시군구 코드 (예: 강남구 11680)
  • DEAL_YMD : 거래 실거래 계약년월 (YYYYMM)
  • serviceKey : 공공데이터포털 발급 보안 인증키[cite: 1]

• 응답 필드(Response): dealAmount(매매가), monthlyRent(월세), rentDeposit(보증금)

엔지니어링 검토 결론:

상가 점포 단위와 부동산 필지 단위를 연결하기 위해 '동코드 + 지번' 기준 복합 외래키를 설계하고, 최근 5개년 분기별 매매·임대 시계열 라인 차트를 출력할 수 있도록 정규화 테이블을 구성해야 함[cite: 1].

RESTful API 설계 명세서

과업지시서의 5대 핵심 모듈을 호출하기 위한 백엔드 엔드포인트 세부 규격[cite: 1]

GET /api/v1/stores/radius
반경 내 점포 공간 쿼리 및 기본 통계 반환[cite: 1]

• Request Query: lat=37.5000&lng=127.0360&radius=500&category=ALL

• Response Data: { status: 200, count: 24, stores: [...], footTraffic: 34210, score: 84 }

POST /api/v1/analysis/compare
A/B 듀얼 후보 상권 1:1 맞대응 대조 판정[cite: 1]

• Request Body: { regionA: { lat: 37.5000, lng: 127.0360, radius: 500 }, regionB: { lat: 37.4979, lng: 127.0276, radius: 500 } }

• Response Data: { scoreA: 84, scoreB: 71, diff: 13, verdict: "A 상권이 경쟁 밀집도 대비 13점 우위" }

GET /api/v1/real-estate/history/:storeId
해당 필지의 최근 5개년 분기별 실거래가 시계열 조회[cite: 1]

• Response Data: { history: [{ quarter: '26-2Q', tradePrice: 19.2, rent: 850 }, { quarter: '25-1Q', tradePrice: 18.2, rent: 800 }] }
